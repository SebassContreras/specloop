# Loopwell marketing

## Project

Marketing/content project. Goal: plan and execute the public launch of Loopwell's
"Instant Export" feature. Audience: existing customers (email list) and prospects
reached via organic channels.

## Doc map

- `planning/product.md` — goal, audience, MVP, constraints.
- `planning/architecture.md` — channels, tools, data sources.
- `planning/roadmap.md` — spec order and status.
- `planning/styles.md` — brand voice, tone, visual references.
- `planning/specs/NNN-name/` — one spec per deliverable.

## Stack & conventions

No software stack — see `planning/architecture.md`'s `Tools` section for the
CMS/ESP/analytics platforms in use.

## Style

Brand voice: direct, no hype adjectives ("revolutionary", "game-changing"). See
`planning/styles.md` for the full brand reference and tone guide.

## Rules for agents

- Never publish or send anything live — draft only, flag for human review/send.
- Never claim a specific speed/performance number ("instant") without a Legal-approved
  source; flag the claim instead of asserting it.
