# 002 — brand-style-refresh — Design

## Approach

Run a stakeholder workshop first to decide scope (voice-only vs. full visual refresh)
before engaging an agency, so the agency brief isn't written against a guess.

## Deliverables

- Workshop output: a one-page scope decision (voice-only vs. full visual refresh).
- Agency selection (if the workshop decides a visual refresh is in scope).
- Ratified guideline document, replacing the current `planning/styles.md` reference
  material once approved.

## Sequencing

Workshop → scope decision → (if needed) agency selection → guideline drafting →
ratification. Cannot start before `001` publishes (per requirements).

## Open questions / deferred

- Budget for an external agency, if one is needed — deferred to whoever approves the
  workshop's scope decision.
